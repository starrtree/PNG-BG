⚙️ API Wiring Note

This app verifies alpha locally in the browser for formats the browser can decode. PNG, WEBP, GIF, SVG, and AVIF may contain transparency; JPG/JPEG and BMP are usually opaque. To generate transparent PNGs through OpenAI from this UI, wire a backend endpoint that calls the Images API with background: "transparent" and output_format: "png". Do not put your API key directly in browser code.
